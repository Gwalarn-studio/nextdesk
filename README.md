# NextDesk

Site bilingue (EN/FR) : carrière, télétravail et IA au travail. Hébergement gratuit sur GitHub Pages.

- `content/<lang>/*.html` : les articles (fragments HTML avec un en-tête JSON `<!--meta … -->`).
- `assets/` : style, scripts (cases à cocher, boutons copier, quiz).
- `python3 build.py` génère le site dans `docs/` (dossier publié par GitHub Pages) (accueil, articles, sitemap, robots.txt).
